How the score works

Bias for a group = (long $ − short $) ÷ (long $ + short $). +100 means all long. −100 means all short.

  • Smart = the sum of the smart cohorts (default: Extremely Profitable and Very Profitable, all-time PnL).
  • Fools = the sum of the fool cohorts (default: Unprofitable, Very Unprofitable and Rekt).
  • Gap = (Smart bias − Fools bias) ÷ 2. It goes from −100 to +100. A large gap means the two groups hold opposite sides.
  • Setup: if Smart is more long than Fools, the setup is SMART LONG. If Smart is more short, the setup is SMART SHORT.
  • Agreement: each smart cohort with enough money must point the same way. If one smart cohort points the other way, the score goes down by up to 50%. This shows as a red flag.
  • Depth: small money gives less trust. The score goes down when the smaller side is near the minimum notional, or when few smart traders hold the market.
  • Score = |Gap| × Agreement × Depth, from 0 to 100.
  • Big money badge: the Apex and Whale size cohorts (account size, not skill). It does not change the score.
  • Held: how long the gap has stayed on the same side and above 15, from the stored history.

Cohorts come from all-time PnL. A trader that was good last year can be wrong now. Use this as a filter to find setups, not as a signal to trade. This is not financial advice.

Data: Hyperdash public API (cohort positioning of Hyperliquid perps), pulled every 15 minutes by a GitHub Action. Spot markets are not in this data.
