Phone push with ntfy (free, no account)

1. Install the ntfy app (iPhone or Android).
2. Pick a long secret topic name, for example cohort-sniper-. Subscribe to it in the app.
3. In GitHub: repo Settings → Secrets and variables → Actions → New repository secret. Name: NTFY_TOPIC. Value: your topic name.
4. Go to the Actions tab → "Update Hyperdash data" → Run workflow → tick Send a test alert. Your phone gets a test push.
You get a push when experts exit or flip a setup, and when a market reaches the alert score.

Which alerts

Default: setup,exit,flip. To change it, add a repository variable named ALERT_TYPES with any of: setup (score reaches the alert score), exit (experts cut the position), flip (experts change side), fade (gap shrinks), add (experts add), new (gap crosses 50). Example: setup,exit,flip,fade.
Cooldowns stop repeats: exit 4h, fade 6h, flip and add 8h, new 12h, setup 24h.

Discord

1. In your Discord server: channel settings → Integrations → Webhooks → New Webhook → Copy Webhook URL.
2. In GitHub, add a repository secret named DISCORD_WEBHOOK_URL with that URL.

Alert score

Default: score 65 or more. To change it: Settings → Secrets and variables → Actions → Variables → New repository variable. Name: ALERT_MIN_SCORE. Value: a number, for example 55.
The alert uses the default Smart and Fools groups and a $50K minimum each side.
How the score works

Bias for a group = (long $ − short $) ÷ (long $ + short $). +100 means all long. −100 means all short.

  • Smart = the sum of the smart cohorts (default: Extremely Profitable and Very Profitable, all-time PnL).
  • Fools = the sum of the fool cohorts (default: Unprofitable, Very Unprofitable and Rekt).
  • Gap = (Smart bias − Fools bias) ÷ 2. It goes from −100 to +100. A large gap means the two groups hold opposite sides.
  • Setup: if Smart is more long than Fools, the setup is SMART LONG. If Smart is more short, the setup is SMART SHORT.
  • Agreement: each smart cohort with enough money must point the same way. If one smart cohort points the other way, the score goes down by up to 50%. This shows as a red flag.
  • Depth: small money gives less trust. The score goes down when the smaller side is near the minimum notional, or when few smart traders hold the market.
  • Score = |Gap| × Agreement × Depth, from 0 to 100.
  • Big money badge: the Apex and Whale size cohorts (account size, not skill). It does not change the score.
  • Funding: the Hyperliquid funding rate as a yearly rate. "Smart side earns" means a position on the smart side gets paid funding now. Funding changes every hour.
  • Trade with: US-listed ways to take the smart side. Options are from the Cboe list of optionable symbols. Leveraged ETFs are found by name in the Nasdaq list of all US listings, every 12 hours. Check the fund before you trade. Single-stock leveraged ETFs reset each day and lose value in choppy markets.
  • IV = at-the-money implied volatility near 30 days. P/C = put/call ratio of open interest. Option data is from Cboe with a 15-minute delay, for the top setups only.
  • Alignment trend: the change of the gap over 1h, 4h, 24h and 7d. ▲ green = the two groups moved further apart on the setup side (stronger). ▼ red = they moved closer (weaker). Hover a box to see the smart bias, fools bias and smart $ change.
  • Experts exiting: the Extremely + Very Profitable cohorts cut 30% or more of their position on the setup side within 1h or 4h (and at least $100K). Experts flipped: their bias changed side. These show as red badges for 6 hours and in the Changes tab.
  • Live data: Hyperdash makes a new cohort snapshot every 5 minutes. The data job checks it about every 45 seconds and publishes each new one. Prices and funding come straight from Hyperliquid every 20 seconds.
  • Track record: each time a market first crosses the signal gap, the page checks the price 4 hours and 24 hours later, on the smart side.

Cohorts come from all-time PnL. A trader that was good last year can be wrong now. Use this as a filter to find setups, not as a signal to trade. This is not financial advice.

Data: Hyperdash cohort positioning, Hyperliquid funding and prices, Nasdaq Trader symbol lists, Cboe option lists and delayed quotes. A GitHub Action publishes each new Hyperdash snapshot (every 5 minutes). Prices and funding are live from Hyperliquid. Spot markets are not in this data.
